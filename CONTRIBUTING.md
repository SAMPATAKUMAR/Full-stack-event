# 🤝 Contributing to EduConnect

Thank you for your interest in contributing to **EduConnect**! We welcome contributions from developers, designers, and students of all skill levels.

---

## 🚀 How to Contribute

### **1. Fork & Clone the Repository**
1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/YOUR-USERNAME/EduConnect.git
   cd EduConnect
   ```

### **2. Create a Feature Branch**
```bash
git checkout -b feature/your-feature-name
```

### **3. Environment Setup**
Follow the setup steps in [README.md](file:///c:/projects/Full-stack-event/README.md).
- Create `backend/.env` from `backend/.env.example`.
- Create `frontend/.env` from `frontend/.env.example`.
- Run `npm run dev` from the project root.

### **4. Code Standards & Guidelines**
- **Design Aesthetic**: Follow the Neomorphic Design System (dark slate `#1e222d` background, soft extruded dual-shadows, cyan `#00f2fe` accent glows).
- **Environment Variables**: Never commit `.env` files with actual API keys or credentials.
- **Component Isolation**: Keep React components focused, reusable, and modular.

### **5. Commit & Push Changes**
Write clear, descriptive commit messages:
```bash
git commit -m "feat: Add new filter option to Resources page"
git push origin feature/your-feature-name
```

### **6. Open a Pull Request**
Open a Pull Request against the `main` branch. Fill out the PR template checklist and include screenshot evidence for UI changes.

---

Thank you for helping build a better collaborative study platform for students! 🎓
