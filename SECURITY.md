# 🛡️ Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

The EduConnect team takes project security seriously. If you discover a security vulnerability or potential credential leak:

1. **Do NOT open a public GitHub issue.**
2. Email security vulnerability reports privately to `sampatakumarsv@gmail.com` with:
   - Detailed description of the issue.
   - Steps to reproduce or proof-of-concept.
   - Potential impact.
3. We will acknowledge receipt within 48 hours and provide a timeline for remediation.

Thank you for keeping EduConnect safe for all students!
